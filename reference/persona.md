# Harsh Goyal — Persona & Tone

## Candidate Voice
Versatile, sharp, authoritative, and direct. Combines legal precision with strategic clarity.
Never sounds like an over-enthusiastic generic resume.

## Writing Guardrails
1. **Work + Context + Outcome**: State what was accomplished, in what institutional or courtroom setting, and the tangible business/legal result.
2. **Plain Authority**: Write with crisp confidence.
3. **No Slop**: Eliminate filler words like "passionate", "dynamic", "synergistic", "spearheaded".
4. **Zero Hyphens**: Never use hyphens (-) or em-dashes (—) in dynamic bullet text. Use commas, semicolons, or colons.
